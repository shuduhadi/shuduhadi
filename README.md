## 🚀 Featured Projects

### 🔐 PyVault: encrypted password manager
[![Tests](https://github.com/shuduhadi/password-manager/actions/workflows/tests.yml/badge.svg)](https://github.com/shuduhadi/password-manager/actions/workflows/tests.yml)

A local password manager in Python. The master password is hashed with bcrypt, entries are encrypted with Fernet (AES) using a PBKDF2-derived key, and data lives in SQLite. Includes a desktop GUI, a CLI, encrypted backups and a Pytest suite that runs on every push via GitHub Actions.

🔗 **[View Repository](https://github.com/shuduhadi/password-manager)**

### 🎣 ClonePhish Detector: phishing detection tool

A Python CLI that flags lookalike domains (typosquats, homoglyph/IDN spoofing, combosquats) and cloned login pages, and searches Certificate Transparency logs for lookalike certificates. Every result gets a 0–100 risk score with plain-English reasons, backed by a Pytest suite on GitHub Actions.

🔗 **[View Repository](https://github.com/shuduhadi/clonephish-detector)**

### 💉 SQL Injection Lab: Campus Shop (Java)
[![lab-check](https://github.com/shuduhadi/sqli-lab-java/actions/workflows/ci.yml/badge.svg)](https://github.com/shuduhadi/sqli-lab-java/actions/workflows/ci.yml)

A hands-on workshop: break a deliberately vulnerable Java web shop with SQL injection (auth bypass, UNION extraction, numeric injection), then fix it with prepared statements, allowlists, safe errors and output escaping. Plain Java + JDBC + SQLite, runs in Docker, with a CI smoke test that checks every attack lands on the starter and fails on the fix.

🔗 **[View Repository](https://github.com/shuduhadi/sqli-lab-java)**

### 🚡 Summit: AI ticket assistant for the Table Mountain Cableway

A public AI agent built on Agentplace that helps visitors choose the cheapest valid tickets for their group, shows the maths and hands off to the official checkout. Guardrails against invented prices, card/ID collection and prompt injection, verified with a 16-case QA suite (16/16 passing).

🔗 **[View Repository](https://github.com/shuduhadi/summit-cableway-agent)** · **[Live Agent](https://tvheehkf2kw7.run.agentplace.io)**
